# الجزائر الخضراء 🌳

تطبيق ويب حقيقي (يعمل كتطبيق مثبّت على الهاتف والحاسوب) لتحدي غرس الأشجار: تصوير الغرسة، جمع النقاط،
لوحة متصدرين وطنية بالولايات، وبث مباشر حقيقي عبر يوتيوب/فيسبوك.

**تصميم المشروع:** Koulaibi Badreddine

هذا ليس عرضاً تجريبياً — بعد اتباع الخطوات أدناه (حوالي 20 دقيقة، ومجاني بالكامل) سيكون لديك **رابط عام
حقيقي** (مثل `algeria-khadra.vercel.app`) يعمل لأي شخص في العالم، على أي هاتف أو حاسوب، والكل يشارك نفس
قاعدة البيانات والنقاط والترتيب في الوقت الحقيقي.

---

## 1) المتطلبات قبل البدء

- حساب Google عادي (لإنشاء مشروع Firebase المجاني — بدون بطاقة بنكية).
- حساب [GitHub](https://github.com) مجاني.
- حساب [Vercel](https://vercel.com) مجاني (يمكن التسجيل مباشرة بحساب GitHub).
- Node.js مثبت على حاسوبك (لتجربة التطبيق محلياً قبل النشر) — من [nodejs.org](https://nodejs.org).

---

## 2) إنشاء قاعدة البيانات (Firebase) — مجانية 100%

1. اذهب إلى https://console.firebase.google.com واضغط **إنشاء مشروع (Add project)**.
2. اختر اسماً مثل `algeria-khadra` واستمر (يمكن تعطيل Google Analytics، غير ضروري).
3. من القائمة الجانبية اذهب إلى **Build → Firestore Database** ثم **Create database**. اختر أي منطقة قريبة
   (مثلاً `eur3` أو `europe-west`) واختر وضع **Production mode**.
4. من القائمة الجانبية اذهب إلى **Build → Authentication → Get started**. من تبويب **Sign-in method** فعّل
   طريقة **Anonymous** فقط (هذا يمنح كل جهاز هوية بدون تسجيل أو كلمة مرور).
5. اذهب إلى ⚙️ **Project settings** (بجانب Project Overview) → انزل إلى **Your apps** → اضغط أيقونة الويب `</>`.
   سمِّ التطبيق `web` واضغط تسجيل. ستظهر لك قيم `firebaseConfig` — احتفظ بها، ستحتاجها في الخطوة القادمة.
6. ارجع إلى **Firestore Database → Rules**، احذف المحتوى الموجود، والصق بدلاً منه محتوى ملف
   `firestore.rules` الموجود في هذا المشروع، ثم اضغط **Publish**.

---

## 3) تجربة التطبيق على حاسوبك

```bash
cd algeria-khadra-app
npm install
cp .env.local.example .env.local
```

افتح `.env.local` وضع فيه القيم التي حصلت عليها من Firebase (كل قيمة أمام السطر المناسب):

```
NEXT_PUBLIC_FIREBASE_API_KEY=...
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=...
NEXT_PUBLIC_FIREBASE_PROJECT_ID=...
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=...
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=...
NEXT_PUBLIC_FIREBASE_APP_ID=...
```

ثم شغّل:

```bash
npm run dev
```

افتح `http://localhost:3000` — التطبيق يعمل الآن ويكتب فعلياً في قاعدة بياناتك.

---

## 4) نشر التطبيق على الإنترنت (رابط عام حقيقي)

### أ) رفع المشروع إلى GitHub
```bash
git init
git add .
git commit -m "الجزائر الخضراء"
```
أنشئ مستودعاً جديداً فارغاً على GitHub، ثم نفّذ الأوامر التي يعرضها لك GitHub لربط المستودع ورفع الكود
(`git remote add origin ...` ثم `git push -u origin main`).

### ب) النشر على Vercel
1. ادخل إلى https://vercel.com وسجّل الدخول بحساب GitHub.
2. اضغط **Add New → Project** واختر المستودع الذي رفعته.
3. في خطوة **Environment Variables**، أضف نفس المتغيرات الستة الموجودة في `.env.local`.
4. اضغط **Deploy** وانتظر دقيقة أو دقيقتين.

بعد الانتهاء، يعطيك Vercel رابطاً عاماً مثل `https://algeria-khadra.vercel.app` — هذا هو رابط تطبيقك
الحقيقي، شاركه مع أي شخص في أي ولاية، وسيدخل الجميع لنفس التطبيق ونفس لوحة الترتيب في الوقت الحقيقي.

---

## 5) تثبيت التطبيق كتطبيق حقيقي على الهاتف (PWA)

بما أن المشروع يحتوي دعم PWA جاهزاً:
- **أندرويد (Chrome)**: افتح الرابط → قائمة (⋮) → **إضافة إلى الشاشة الرئيسية / تثبيت التطبيق**.
- **آيفون (Safari)**: افتح الرابط → زر المشاركة → **إضافة إلى الشاشة الرئيسية**.
- **الحاسوب (Chrome/Edge)**: ستظهر أيقونة تثبيت ⊕ في شريط العنوان.

سيظهر التطبيق بأيقونته الخاصة ويعمل بملء الشاشة كأي تطبيق مثبّت، بدون متصفح ظاهر.

---

## 6) ملاحظات مهمة

- **التكلفة**: كل الخدمات المستخدمة (Firebase Spark + Vercel Hobby) مجانية ضمن حدود سخية تكفي آلاف
  المستخدمين شهرياً دون أي دفع أو بطاقة بنكية.
- **الصور**: يتم ضغط صورة كل غرسة تلقائياً قبل الحفظ لتبقى خفيفة وسريعة.
- **البث المباشر**: التطبيق لا يستضيف بثاً مباشراً بنفسه (ذلك يتطلب خوادم بث مكلفة)، بل يتيح لأي مستخدم بدء
  بث حقيقي من يوتيوب أو فيسبوك من هاتفه، ولصق رابطه في التطبيق ليظهر فيديو مباشر حقيقي مضمَّن للجميع.
- **الأمان**: قواعد Firestore (`firestore.rules`) تمنع أي مستخدم من تعديل نقاط غيره أو حذف غرسات الآخرين.
- **نطاق خاص بك**: من إعدادات المشروع في Vercel → Domains، يمكنك ربط اسم نطاق خاص (مثل
  `aljazair-alkhadra.dz`) بدلاً من رابط vercel.app.
